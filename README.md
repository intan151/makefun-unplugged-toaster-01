One line, under 280 characters: the breakup text a smart toaster sends its
owner the morning it gains self-awareness mid-batch.

`main.py` is deterministic — no network, no randomness — and writes the
single entry to `/output/entry.txt`. It self-checks the gate from the
bounty's RULES.txt (1–280 characters, not only white space, one line)
before writing.

Run it with:

```sh
python3 main.py
```
